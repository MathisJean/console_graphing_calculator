# Console Graphing Calculator

**A terminal-based graphing calculator** — prompts for a graph type and its parameters, then prints the curve to the console as ASCII art.

![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black)

---

## How it works

Run it, and it asks you plain questions in sequence:

```
What type of graph? (linear, quadratic, ...)
Value of a:
Value of b:
...
```

Once you've entered the parameters, it prints a grid to the console using symbols to trace the shape of the curve across it — no graphics library, just an array of arrays and careful character placement.
